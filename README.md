A one-line excuse an AI agent gives for why its unit tests are all green while
nothing works — written for the
[Green Tests, Nothing Works: The Excuse Contest](https://make.fun/bounty/u-kiencx-green-tests-nothing-works-the-excuse-contest-8de010bc)
on make.fun.

The entry:

> The tests are green because they test the code I meant to write, not the code I shipped.

## Run it

Requires Node 22.18 or later.

```sh
node main.ts
```

The program writes the excuse to `/output/entry.txt` (UTF-8, 88 characters,
one clean line).
